# Introducción y Visión General
El proposito de este proyecto es poner en practica los conocimientos que abarca el front-end como el back-end como la experiencia del usuario, el diseño, la creación de bases de datos y la aplicación de CRUD tanto en SQL como en las APIs REST.

## Alcance
El proyecto incluye:
  1. Secciones de información para la marca (Hero, Services, About Us, Products, Contact y Terms and Conditions)
  2. Registro e Inicio de sesión
  3. Interfaz de cliente (Historial de compras registradas)
  4. Interfaz de administrador (CRUD)
  5. Descargar factura por cada compra registrada

El proyecto excluye la pasarela de pagos, la validación de correos electronicos existentes y la verificacion de dos pasos.
