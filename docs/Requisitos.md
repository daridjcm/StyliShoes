# Requisitos
**- Requisitos funcionales:**
  1. El usuario debe poder iniciar sesión
  2. El usuario debe poder crear una cuenta nueva
  3. El usuario debe poder agregar producto, eliminar o modificar en su defecto
  4. El usuario debe poder navegar fluidamente en los hipervinculos

**- Requisitos no funcionales:**
  1. El tiempo de carga no debe superar 2 segundos
  2. La interfaz de cliente no deberia mostrar datos de otros usuarios
  3. La interfaz de administrador al modificarse un producto, no deberia borrarse la imagen si no fue remplazado por otra
  4. La sección de productos debera mostrar los cambios efectuados por el administrador.
